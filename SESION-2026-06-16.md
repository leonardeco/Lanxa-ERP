### 2. Pagos a proveedores integrados en Cartera

**Problema resuelto:** Las CxP eran manuales y no tenían vínculo con las compras.

**Solución implementada:**

#### Backend

**`contabilidad/models.py`**
```python
# Campo nuevo en CuentaPorPagar:
compra_id = Column(Integer, nullable=True)  # FK lógica a compras_documentos
```
> **Nota migración SQLite:** se aplicó con `ALTER TABLE cuentas_por_pagar ADD COLUMN compra_id INTEGER;` — si se hace fresh install, `create_all` la crea automáticamente.

**`compras/router.py` — `confirmar_compra`**
- Al confirmar una compra, se crea automáticamente una `CuentaPorPagar` con:
  - `numero_documento` = número de la compra (ej. `SOG-CP-0001`)
  - `valor` = `compra.total`
  - `fecha_vencimiento` = la de la compra
  - `compra_id` = `compra.id`
  - `concepto` = `"Compra SOG-CP-0001 — Ref: FV-TEST-001"`
- Verifica que no exista ya una CxP con ese número (idempotente)

**`contabilidad/router.py` — `abonar_cxp`**
- Al registrar un abono en una CxP con `compra_id`, sincroniza `CompraDocumento.estado_pago`:
  - Saldo = 0 → `estado_pago = "Pagado"`
  - Saldo > 0 → `estado_pago = "Parcial"`

**`contabilidad/router.py` — `anular_cxp`**
- Si la CxP tiene `compra_id`, también pone `CompraDocumento.estado_pago = "Anulado"`

**`contabilidad/schemas.py`**
- `CxPResponse` ahora incluye `compra_id: Optional[int] = None`

#### Frontend

**`carteraApi.ts`** — `CxP` interface añade `compra_id?: number`

**`CarteraView.tsx` — tab CxP**
- Nueva columna **Origen**: badge `📥 Compra` (azul) o `Manual` (gris)
- Botón "Abonar" renombrado a **"Pagar"** para CxP de proveedores
- `colSpan` actualizado de 9 a 10
